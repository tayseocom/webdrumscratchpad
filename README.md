# Sequence Lab

Sequence Lab is a lightweight Web Audio drum and bass sequencer that lets you program 16-step patterns, apply swing, and randomize parts for inspiration. Serve the directory with any static file server and open `sequencer.html` to start exploring.

## Development

Open a local server in this directory, for example:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000/sequencer.html](http://localhost:8000/sequencer.html) to interact with the sequencer.
